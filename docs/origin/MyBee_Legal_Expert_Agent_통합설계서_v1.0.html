01

결론 — ‘판사 출신 20년차’ 수준은 모델 하나를 키워서 얻는 것이 아니다

핵심 판단. 판사 출신 20년차 변호사의 역량은 ① 요건사실·증명책임으로 사건을 분해하는 사고 절차, ② 증거로 사실을 인정하는 경험칙, ③ 판례를 사실관계로 구별하는 독해, ④ 절차·기한 감각, ⑤ 근거가 모자랄 때 결론을 미루는 절제로 이루어집니다. 이 가운데 ①④⑤는 데이터·Skill·결정적 도구로 외부화할 수 있고, ②③은 자문단이 만든 기준과 서로 다른 모델의 독립 판단으로 근접시킬 수 있습니다. 최종 판단과 책임은 자격자에게 남습니다.

도달 가능성에 대한 정직한 판정. 2026년 9월 현재 AI가 경력 변호사의 판단형 종합을 대체한다는 독립 근거는 없습니다. 미국 법률조사 평가에서도 변호사는 맥락 이해·복합 관할·판단형 종합에서 앞섰고[P2], 한국 변호사시험 기반 평가도 서술형에서 큰 격차를 보고합니다[P3][P4]. 그래서 이 설계는 목표를 “전체적으로 같은 수준”이 아니라 과업군별 블라인드 비열등 판정(12장 E1→E2→E3)으로 정의하고, 과업마다 도달 여부를 따로 선언합니다.

6.2 결론 표현 규칙

써야 하는 것

  • 결론을 좌우하는 요건(decisive=true)과 그 충족 상태
  • 결론이 바뀌는 조건(“E03의 도달이 증명되면 …”)
  • 해석이 갈리는 쟁점의 양론과 각 근거의 권위

  • “승소 가능성 70%” 같은 수치 확률(G-13)
  • 확인되지 않은 사실을 전제로 한 단정

6.3 재판부 관점 검토(Bench EA)는 토론이 아니다

역할극 기반 법정 시뮬레이션 연구에서 토론을 뺐을 때보다 지식베이스를 뺐을 때 성능이 더 떨어졌습니다(조문 F1 0.203 → 토론 제거 0.171 · 지식 제거 0.145)[P13]. 그래서 Bench EA는 재판부를 연기하며 주고받는 대신, 완성된 초안을 판결서 이유 구조(쟁점별: 인정사실 → 법리 → 포섭 → 판단)로 한 번 재배열해 빈칸을 찾는 검토자로 둡니다.

  2. 산출물 준비: AI 산출물과 기준본의 서식·길이 흔적을 제거하고 무작위 라벨을 붙입니다(review_artifact).

  4. 결론 예측(EP-09) 오염 통제: 판결서의 “인정 사실”은 법원이 이미 걸러낸 사실이므로 그대로 입력하면 성능이 과대평가됩니다. 입력은 자문단이 판결 전 단계 자료(주장·증거 목록) 형태로 다시 쓴 중립 사실관계로 하고, 판결 선고일이 모델 학습 시점과 원문 스냅샷 이후인 사례를 우선합니다.
  5. 보고: 평균 점수와 함께 표본 수, 과업군 분포, 중대 오류 사례, 불일치 사례를 보고합니다. 표본에서 중대 오류 0건은 발생 확률 0을 뜻하지 않습니다(Wiki v3 9장).
