01

결론 — 조건부로 효과적이다. 다만 효과를 내는 것은 ‘토론’이 아니다

답: 멀티에이전트·멀티 LLM 구성은 법률 해석의 정확도와 근거 신뢰도를 높일 수 있습니다. 그러나 연구를 분해해 보면 개선의 대부분은 ① 조문 원문·구조·시점을 가져오는 검색과 결정적 도구, ② 서로 다른 동급 모델의 독립 답변 비교, ③ 원문에 대조하는 검증 단계에서 나옵니다. 영상이 강조한 “여러 에이전트가 주고받으며 합의에 이르는 토론”은 같은 계산량으로 비교하면 효과가 거의 없거나, 오히려 맞는 답을 틀린 답으로 바꾸는 사례가 반복 보고됩니다.

한 법률 안의 조항 간 연결(준용·단서·항호목 참조)과 다른 법률과의 연결을 멀티에이전트가 개선하는지 직접 측정한 논문은 찾지 못했습니다. 이 두 과제는 단일 모델이 약하다는 증거만 있고, 해법의 효과는 아직 간접 근거입니다. 한국법 대상 멀티에이전트 연구도 없습니다.

효과 확인

  • 서로 다른 계열 모델의 다수결 — COLIEE 2026 조문 포섭 1위(단일 최고 84.9% → 이질 앙상블 93.0%)[30]
  • 검색·검증 에이전트 분리 — 인용 누락률 98.9% → 13.2%[21]
  • 요건을 형식화해 솔버로 판정 — 세법·양형 규칙에서 개선[28][29]

효과 불확실

  • 같은 모델 여러 개의 토론 — 모델에 따라 +8%p 또는 −9%p[31]
  • 원고·피고·판사 역할극 — 개선 폭보다 검색 기여가 큼[24]
  • 조항 간·법률 간 연결 추적 — 직접 연구 없음

역효과 확인

  • 토론 라운드 증가 → 정확도 지속 하락[31]
  • 강한 추론 모델에 복잡한 다단 파이프라인 → 하락(Gemini 2.5 Flash 96.9 → 77.1)[29]
  • 검색이 섞이면 약한 모델이 앙상블을 끌어내림(86.6 vs 단일 91.5)[30]
  • 외부 근거 없는 자기 비판 → 악화[9]

실무 권고 요약

  1. 조항 연결·시점은 에이전트가 아니라 데이터로 푼다. 준용·위임·특례·정의·부칙 관계를 조문 그래프와 시점 DB에 넣고, 에이전트는 그것을 조회합니다.
  2. 해석은 서로 다른 회사의 동급 모델이 서로 보지 않고 독립적으로 작성한다. 약한 모델을 섞으면 평균이 떨어집니다.[12]
  3. 일치는 정답의 증거가 아니다. 최신 모델들은 틀릴 때 같은 오답을 고르는 비율이 높습니다(우연 33% 대비 약 60%).[16] 일치해도 원문 감사를 생략하지 않습니다.
  4. 불일치는 합의로 없애지 말고 분류한다. 근거·시점 오류는 반려하고, 진짜 해석 대립은 양론을 병기해 변호사에게 넘깁니다.
  5. 토론은 최대 1회의 구조화된 반박으로 제한한다. 반복 토론은 동조와 정확도 하락을 부릅니다.[13][14]
  6. 도입 효과는 같은 계산량의 단일 강한 모델과 비교해 증명한다. 그렇지 않은 개선 수치는 대부분 계산량 차이입니다.[18]

02

질문을 과제로 나누기 — 변호사 수준 해석은 네 층으로 이루어진다

“변호사 수준으로 해석한다”는 하나의 능력이 아닙니다. 서로 다른 오류가 생기는 네 층으로 나누어야 어떤 구성이 어디에 효과가 있는지 판정할 수 있습니다.

층실무에서 하는 일단일 LLM에서 확인된 약점
① 같은 법률 안의 조항 연결항·호·목 구조, 단서, “제○조를 준용한다”, 정의 조항, 적용 제외 조항을 따라가 요건을 완성형제 하위조항 혼동(§152(d)(2)(C)를 (D)로 인용), 가상 법률 깊이가 3×3으로 깊어지면 정확도 100% → 81%[33]. 한국 KBL에서 조문 내용과 조문 번호 연결 과제 정답률 23.0~49.0%[38]
② 다른 법률과의 연결시행령·시행규칙 위임, 특별법 우선, 타법 준용, 일반법 보충, 행정해석·판례 연결도구 사용 에이전트도 1단계 과제 약 93% → 5단계 약 61%로 하락[40]. 다관할 문항은 평균 14점 낮음[46]
③ 시점사실 발생일 기준 유효 조문, 부칙 적용례·경과조치, 판례 변경입력으로 개정 조문을 주어도 학습 기억 속 개정 전 문언을 답하는 현상[34]
④ 해석 차이문리·체계·목적론적 해석, 판례와 유권해석의 차이, 학설 대립, 반대 논거 대응같은 질문을 온도 0으로 20회 물어도 답이 바뀌는 비율 10.6~50.4%[35]. 미국 판례 질의 할루시네이션 58~88%[44]

여기에 ⑤ 요건 포섭(사실이 조문 요건을 충족하는가)과 ⑥ 인용 정확성이 겹칩니다. 연구 대부분은 ⑤·⑥을 측정했고, 사용자가 질문한 ①·②·④는 정면으로 측정한 연구가 드뭅니다.

03

영상의 군집 방식(Solver·Critic·Selector)을 법률에 대입하면

공유된 영상 요약이 제시한 구성 요소마다 법률 분야 근거를 대조했습니다.

영상의 구성 요소법률 해석에 대입했을 때판정
고온도 Solver 다수가 가설을 쏟아냄법률 답변은 온도 0에서도 이미 불안정합니다[35]. 무작위성을 키우면 서로 다른 결론만 늘고, 틀린 결론을 걸러낼 기준이 따로 필요합니다. 다양성은 온도보다 서로 다른 모델·서로 다른 검색 계획에서 얻는 편이 근거가 있습니다[11][30].변형 필요
온도 0 Critic이 오류 검증외부 근거 없이 LLM이 비판하면 결과가 나빠질 수 있습니다(CommonSenseQA 75.8 → 41.8)[9]. 초안과 같은 모델이 심사하면 자기 글을 선호합니다[17]. 비판자는 조문 원문·인용 실존·시점을 결정적 도구로 대조해야 효과가 있습니다.조건부 유효
Selector가 살아남은 조각을 합성합의 압력이 강하면 맞는 답이 틀린 답으로 바뀌는 빈도가 반대보다 높습니다[13]. 해석 대립이 있는 쟁점에서 합성은 소수설·반대 판례를 지워 버릴 위험이 있습니다.위험
실패 경로를 공유 메모리에 기록(페로몬)판결 예측 연구에서 기억 제거 시 조문 정확도 90.56 → 86.55[27]. “이 조문은 해당 기준일에 시행 전” 같은 불가 조건 기록은 재사용 가치가 큽니다.유효
Lean·Coq 형식 검증기로 무결성 보증요건 조합·세액 계산 같은 규칙형 조문은 솔버 제거 시 성능이 크게 떨어질 만큼 기여합니다(G-F1 39.08 → 25.29)[28]. 그러나 “정당한 사유”, “사회통념상” 같은 불확정 개념과 학설 대립은 형식화할 수 없고, 자연어 → 논리식 변환 오류는 검증기가 잡지 못합니다.규칙형 조문에 한정
MCTS 가지치기로 비용 절감법률 분야 적용 연구를 찾지 못했습니다.근거 없음

과제별 판정 — 사용자 질문에 대한 항목별 답

과제멀티에이전트·멀티 LLM 효과근거 수준실제로 효과를 낼 요소
① 같은 법률 안의 조항 연결직접 측정 연구 없음. 단일 모델의 하위조항 혼동과 깊이 증가 시 하락은 확인됨. 형식화·다단 파이프라인이 규칙형 세법 조문에서 개선(비추론 모델)직접 근거 없음조문 구조 그래프(항·호·목, 단서, 준용, 정의, 적용 제외)를 결정적으로 펼쳐 주는 도구. 에이전트 수는 부차적
② 다른 법률과의 연결다단계·다관할에서 AI 성능이 떨어진다는 증거는 강함. 검색 역할 분리·그래프 RAG가 유망하나 한국법 측정 없음간접위임·특별법·타법 준용 관계 그래프 + 독립 검색 계획을 가진 두 번째 에이전트(누락 탐지)
③ 시점(개정·부칙)에이전트로 해결된다는 근거 없음. 모델이 기억 속 옛 조문을 답하는 문제는 데이터 문제해당 없음시점 DB와 부칙 적용 규칙의 결정적 판정
④ 해석 차이·학설 대립여러 모델은 대립의 존재를 드러내는 데 유용(단일 모델도 호출마다 답이 바뀜). 토론으로 옳은 해석에 수렴한다는 근거는 없고, 동조로 소수 해석이 사라질 위험이 확인됨탐지에 유효 · 결정에 부적합블라인드 독립 해석 → 불일치 분류 → 양론 병기 → 변호사 판단
⑤ 요건 포섭이질 동급 모델 앙상블 효과가 가장 확실. 같은 모델 토론은 혼합강함서로 다른 계열 동급 모델 3개 이상 다수결, 검색 결과 정제 후 투입
⑥ 인용 정확성검색·검증 에이전트 분리로 근거 누락 대폭 감소. 상용 RAG도 17~33% 오류가 남음강함 (0은 아님)인용 실존·조문 번호·원문 일치의 결정적 대조, 발행 전 차단

09

권장 구조 — 근거가 지지하는 범위에서만 에이전트를 쓴다

설계 원칙과 각각의 근거

원칙근거
조항·법률 연결은 그래프가 펼치고 LLM은 읽기만하위조항 혼동[33], 조문-번호 연결 23~49%[38], 다단계 하락[40]
해석자는 서로 다른 회사의 동급 모델이질 앙상블 이득[30], 약한 모델 혼합 시 손해[12][13]
해석자끼리 답을 보여 주지 않음동조에 의한 조기 합의 붕괴[14], 토론 이득은 다수결이 설명[10]
반려는 1회, 토론 라운드 없음라운드 증가 시 정확도 하락[31]
감사자는 원문을 쥐고, 초안과 다른 모델외부 근거 없는 자기 교정 악화[9], 자기 선호[17]
일치를 검토 면제 사유로 쓰지 않음상관된 오류 약 60%[16], 상용 RAG 17~33%[43]
해석 대립은 출력 형식으로 보존같은 질문에도 답이 10.6~50.4% 바뀜[35]. 변호사는 판단형 종합에서 우세[46]
규칙형 조문(세액·기간·요건 조합)은 솔버·코드솔버 기여 최대[28], 세법 형식화[29]
강한 추론 모델에는 파이프라인을 얇게추론 모델에서 다단 파이프라인 역효과[29], 같은 예산 단일 우세[18]
검색 결과를 정제한 뒤 앙상블에 투입관련 없는 조문이 섞이면 앙상블이 단일에 짐[30]

피해야 할 구성

  • 같은 모델을 여러 개 띄워 온도만 바꾸고 “군집”이라 부르는 구성
  • 합의가 날 때까지 반복하는 토론 루프 — 비용은 늘고 소수 해석은 사라짐
  • 초안 모델이 스스로 “검토했음”을 표시하는 자기 검증
  • 에이전트 합의율을 확신도로 바로 보여 주는 화면(보정되지 않은 수치)
  • 작은 로컬 모델을 비용 절감용 해석자로 섞는 구성

MyBee Legal/Tax Agent 기획서 v1.4와의 대조

기획서 v1.4는 이미 이번 조사 결과와 같은 방향을 택하고 있습니다. 주 EA와 다른 기반 모델로 교차검증(설계지시문 제6.5.5조 인용), 블라인드 1단계 뒤 공격 2단계로 나눈 Opponent Agent(14장), 결정적 검사 중심의 Evidence Auditor와 Legal Trust Gate(13장), 기준일을 둔 Golden Set(19장)이 해당합니다. 아래는 근거에 비추어 보강할 점입니다.

번호v1.4 현재근거보강 제안
P-01교차검증 EA는 “다른 기반 모델”약한 모델 혼합 시 평균 하락[12][30]“다른 기반 모델”에 동급 요건을 추가: HOLDOUT에서 주 EA 대비 성능 차이가 기준 이내인 모델만 교차검증에 등록. Local LLM 교체(16장) 시에도 같은 기준
P-02G-05 불일치 → 자격자 검토. 일치 시 규정 없음상관된 오류[16]일치를 검토 완화 사유로 쓰지 않음을 명시. 일치 사안도 위험등급별 표본 검토 비율을 데이터로 등록
P-03interpretation_agreement 0.88을 확신도 벡터 항목으로 사용합의 ≠ 정답[14][16]이 항목은 Golden Set에서 정답률과 따로 보정(ECE)한 뒤에만 게이트 기준에 사용. 보정 전에는 “불일치 신호”로만 사용
P-04G-05 불일치는 한 종류대립 탐지에 유효, 결정에 부적합(8장 ④)불일치를 근거·시점 오류(반려 1회)와 해석 대립(양론 병기 필수)으로 나누는 분류 코드 추가. LegalOpinion 출력 스키마에 대립 해석 목록 필드
P-05Opponent 2단계 공격 후 재작성 상한 존재라운드 증가 시 하락[31]공격 → 재작성 반복을 1회로 고정하고, 재작성 후 재공격하지 않음을 명시
P-06Semantic 검사는 NLI + LLM 판정자기 선호[17]Semantic 판정 LLM은 해당 의견을 쓴 모델과 다른 모델로 강제
P-07Legal Knowledge Graph(10장)조항·법률 연결 직접 연구 없음(8장 ①②)Golden Set에 조항 연결 전용 사례군 신설: 준용·단서·정의·위임·특별법 우선이 결론을 바꾸는 사례. 연결 누락률을 독립 지표로 측정
P-08Benchmark는 구성별 비교 기준 미정계산량 일치 비교 필요[18]배포 게이트에 “같은 토큰 예산의 단일 최강 모델 + 같은 RAG” 대조군을 두고, 멀티 구성의 이득이 대조군을 넘을 때만 채택
P-09—답변 불안정 10.6~50.4%[35]같은 질의 반복 호출 시 결론 변동률을 모델 등록 지표로 추가

위 제안은 기획서 v1.4 본문 중 13·14·19장과 교차검증 조항만 대조한 결과입니다. 반영 시 설계지시문 v4.6의 조항 번호·약어 체계와 다시 대조해야 합니다.

한국법 검증 실험 설계 — 효과를 직접 측정하는 방법

한국법 대상 근거가 없으므로 도입 전에 자체 실험으로 확인해야 합니다. 법제처 법령해석례와 국세청 질의회신은 정답(유권해석)과 적용 조문이 공개된 사례여서 조항 연결 평가셋으로 쓰기 좋습니다. 다만 해석례의 결론을 정답으로 쓸 때도 기준일을 붙여 두어야 합니다.

조건구성확인하려는 것
A 기준단일 최강 추론 모델 + 같은 RAG·그래프, 호출 1회출발점
B 같은 예산 단일A 모델을 N회 샘플링 후 다수결 (토큰 예산 = D와 동일)계산량만으로 얻는 이득
C 이질 독립서로 다른 회사 동급 모델 3개 독립 답변 + 다수결모델 다양성의 순수 이득
D 이질 + 감사C + 원문 감사 + 1회 반려검증 단계의 이득
E 이질 + 토론C + 서로의 답을 보는 2라운드 토론토론의 추가 이득 또는 손해
F 그래프 제거D에서 조문 그래프 펼치기 제거조항 연결에서 그래프의 기여

측정 지표

지표정의
결론 정확도유권해석·확정 판례 결론과 일치
적용 조문 F1결론에 필요한 조문(준용·위임 대상 포함) 집합 대비
연결 누락률결론을 바꾸는 단서·준용·특별법 조항을 빠뜨린 비율
시점 오류율기준일에 유효하지 않은 조문 버전 사용
대립 탐지 재현율판례·해석례가 갈리는 쟁점에서 양론을 모두 제시한 비율
결론 변동률같은 입력 5회 반복 시 결론이 바뀐 비율
건당 비용·지연토큰, 초 단위 지연

판정 규칙: C·D가 B를 통계적으로 넘지 못하면 멀티 LLM 구성을 채택하지 않습니다. E가 D보다 낮거나 같으면 토론 단계를 두지 않습니다. 결과는 법 영역(민사·형사·공법·세법)별로 따로 봅니다. KBL에서 공법만 검색 효과가 역전된 사례가 있기 때문입니다[38].

법적 경계 — 구성이 좋아도 바뀌지 않는 것

규범내용설계 영향
변호사법 제109조[65]변호사가 아닌 자가 금품 등 이익을 받거나 약속하고 법률 상담·문서 작성 등을 취급하면 7년 이하 징역 또는 5천만 원 이하 벌금. 완전 무료 AI 서비스는 이익 요건이 없어 저촉되지 않는다는 견해가 보도됨에이전트 수와 무관하게 유상 SaaS가 타사에 의견을 주면 위험. 발행 주체는 자격자(기획서 v1.4 2장)
인공지능기본법(2026-01-22 시행)[66]고영향 AI 영역에 법률 서비스·재판은 명시되지 않음. 권리·의무에 중대한 영향을 주는 판단 영역의 확대 해석이나 시행령으로 해당될 여지. 고영향·생성형 AI 사전 고지 의무해당 여부 미결(기획서 v1.4 O-02). 사람 감독 구조는 해당 여부와 무관하게 유지
법원 AI 가이드라인·규칙 개정 추진[57][58]AI 사용·검증 과정 공개 명령 가능, 허위 인용 과태료 검토의견마다 사용 모델·근거·감사 결과·검토자 이력을 보존해야 함
대한변협[64]2025-07 법률 AI TF 구성, 지침 논의 중. 공식 채택 지침은 확인하지 못함지침 확정 시 재검토
이 장은 설계 영향 정리이며 법률의견이 아닙니다. 인공지능기본법 고영향 영역 해석은 법안 문언 해설 자료에 기댄 것이어서 국가법령정보센터 확정 조문으로 다시 확인해야 합니다.

한계와 확인 범위

  • 확인 방법: 논문은 arXiv·ACL Anthology·학회 논문집 페이지에서, 사례는 1차 자료 또는 보도에서 확인했습니다. 일부 수치는 페이지 본문 추출을 거쳤으므로 외부 인용 전에 원 논문 표로 다시 확인하십시오. 확인하지 못한 수치는 싣지 않았습니다(LawLuo·G-DSR 수치, VERDICT 멀티에이전트 제거 수치 등).
  • 동료 심사: 2026년 프리프린트(L-MAD, VERDICT, L4L, Tran & Kiela, L-MARS v4 등)는 심사 전 자료입니다.
  • 관할 편중: 법률 연구는 중국 형법·판결, 미국 세법·판례, EU GDPR, 일본 민법에 집중되어 있습니다. 한국법 멀티에이전트 연구는 없습니다.
  • 과제 불일치: 사용자 질문의 핵심인 같은 법률 안 조항 연결, 법률 간 연결, 해석 대립을 직접 측정한 연구는 없어 8장 판정 중 ①②④는 간접 근거입니다.
  • 제품 자료: 상용 제품의 구조 설명과 엘박스·슈퍼로이어 수치는 자사 발표이며 독립 검증되지 않았습니다.
  • 시점: 모델 세대 교체가 빨라 2024년 이전 모델 기준 결과는 현재 모델에서 달라질 수 있습니다(7장).
  • 보고서 범위: 문헌·사례 분석이며, 제안한 구조와 실험의 효과를 직접 측정하지 않았습니다.
